O que fazemos

Desenvolvemos e mantemos integrações que conectam o sistema de gestão de um lojista aos marketplaces em que ele vende. O objetivo é eliminar os dois problemas mais comuns de quem opera nos dois canais ao mesmo tempo: estoque divergente entre a loja física e a virtual, e pedido redigitado à mão no ERP para conseguir emitir a nota fiscal.

O trabalho é entregue de duas formas: como módulo embarcado no ERP do cliente, e como integrador independente, que se conecta a sistemas de gestão de terceiros.

Marketplaces integrados

Shopee Amazon Magalu Mercado Livre TikTok Shop

O que a integração faz

Pedidos

Importa o pedido do marketplace para o ERP gerando venda, itens, pagamento e emissão fiscal correspondente, sem redigitação.

Estoque

Sincroniza o estoque físico para o marketplace, por alteração e também de forma periódica, evitando venda de item indisponível.

Catálogo

Importa os anúncios do marketplace, vincula ao produto do ERP e permite cadastrar produtos novos a partir do catálogo do lojista.

Expedição

Despacho do pedido, emissão e download de etiqueta de envio e tratamento de solicitações de cancelamento.

Como os dados são tratados

  • O sistema é executado na infraestrutura do próprio lojista, e os dados dos pedidos são gravados no banco de dados dele. Não há servidor intermediário nosso armazenando dados de compradores.
  • As credenciais de acesso às APIs ficam criptografadas no banco de dados do lojista.
  • Cada loja autoriza individualmente o aplicativo, pelo fluxo oficial de autorização do marketplace. Não há acesso compartilhado entre clientes distintos.
  • Os dados pessoais recebidos limitam-se ao necessário para processar o pedido e emitir o documento fiscal exigido pela legislação brasileira.

O detalhamento completo está na Política de Privacidade.

About us (English)

TI Denis Ripol — Desenvolvimento de Sistemas is an independent software developer based in Cuiabá, Brazil. We build and maintain integrations between merchants' ERP systems and online marketplaces.

Our integration currently supports Shopee, Amazon, Magalu, Mercado Livre and TikTok Shop, covering order import with automatic Brazilian tax document issuance, stock synchronisation, catalogue import and product listing, shipping and cancellation handling.

The software runs on each merchant's own infrastructure and stores order data in the merchant's own database. We operate no intermediary server holding buyer data. API credentials are stored encrypted, and each shop authorises the application individually through the marketplace's official authorisation flow.
